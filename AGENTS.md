# SIMRED — administrador

- Inspecciona el módulo y sus llamadas API antes de cambiarlo. Sigue la estructura de Vue 3, Vite, TypeScript y Composition API con `<script setup>`.
- Reutiliza los componentes de Metronic 9 y Tailwind, los clientes API y los stores de Pinia. Mantén consistentes los formularios, filtros, tablas y estados de carga y error.
- Confirma rutas, campos, permisos y reglas de negocio contra el backend. Distingue lo implementado de lo previsto y justifica las dependencias nuevas.
- Usa Web Design Guidelines para revisar accesibilidad y usabilidad dentro de la identidad visual de Metronic.
- Ejecuta `npm run type-check` y las verificaciones pertinentes. Para Playwright, usa una instancia local o de pruebas autorizada y cuentas y datos de prueba. Documenta los cambios y las comprobaciones ejecutadas.
